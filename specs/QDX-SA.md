# QDX-SA v0.1

Draft optional acceleration extension to QDX-S.

Possible capabilities: READ_ANY, MULTI_WRITE, COPY_STREAM, CHAINED_IO, QUEUED_COMMANDS.

These features must remain optional. Software must be able to fall back to ordinary QDX-S operations. QDX-SA does not define codecs, mixing, editing, file formats, or application protocol policy.
